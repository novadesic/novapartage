# Contributing to NovaPartage

Thank you for your interest in contributing to NovaPartage.

## Before you start

1. Read [SECURITY.md](SECURITY.md) if you discover a vulnerability.
2. Follow the setup in [README.md](README.md) and [docs/INSTALL.md](docs/INSTALL.md).

## Development setup

See the main [README.md](README.md) and `env.example` for local installation.

## Pull requests

1. Fork the repository.
2. Create a feature branch from `main`.
3. Keep changes focused and tested.
4. Sign your commits with the **Developer Certificate of Origin (DCO)**:

```text
Signed-off-by: Your Name <your.email@example.com>
```

Add with: `git commit -s -m "your message"`

By signing off, you certify that you have the right to submit the contribution under the Apache-2.0 license.

## Code review

- All PRs require review before merge.
- Security-sensitive areas (auth, JWT, encryption, Docker secrets) need senior review.
