# Assets pour les templates NovaPartage

Ce répertoire contient les images et ressources utilisées dans les templates d'emails.

## Logo

Placez le logo NovaPartage dans ce répertoire avec le nom `logo.png`.

Le logo est référencé dans les templates via `cid:logo@novapartage`.

## Formats supportés

- PNG (recommandé)
- JPG/JPEG
- GIF
- SVG

## Taille recommandée

- Logo principal : 200px de large maximum
- Haute résolution (@2x) : 400px de large maximum
